# 견적서 계산기 — 설계 문서

## 개요

1인 영상제작 법인을 위한 단일 페이지 견적 계산기. 고객이 레퍼런스 링크와 촬영 옵션을 입력하면 실시간으로 금액이 계산되고, 견적서를 PNG로 저장하거나 사업자에게 이메일로 요청할 수 있다.

## 가격표

| 항목 | 단가 |
|------|------|
| 촬영 (1회) | 500,000원 |
| 편집 (결과물 1분) | 300,000원 |
| 드론 촬영 | 500,000원 |
| 추가 촬영 인원 (1인) | 300,000원 |

## 입력 필드

- 고객명 (텍스트)
- 레퍼런스 링크 (URL, 여러 개 추가 가능)
- 촬영 횟수 (숫자, 기본값 1)
- 결과물 길이 (숫자, 단위: 분)
- 드론 촬영 여부 (체크박스)
- 추가 촬영 인원 수 (숫자, 기본값 0)

## 견적 계산 (실시간)

```
촬영비    = 촬영횟수 × 500,000
편집비    = 결과물분 × 300,000
드론      = 500,000 (선택 시)
추가인원  = 인원수 × 300,000
합계      = 위 항목 합산
```

## 출력

1. **견적서 저장** — html-to-image로 PNG 다운로드
2. **견적 요청** — 고객명, 입력값, 레퍼런스 링크, 견적 금액을 사업자 이메일로 발송 (Resend)

## 기술 스택

- Next.js 15 (App Router) + TypeScript + Tailwind CSS
- Resend (이메일 발송)
- html-to-image (PNG 저장)

## 환경변수

```
RESEND_API_KEY=
SENDER_EMAIL=
MANAGER_EMAIL=
```

## 범위 외

- 고객 이메일 발송 없음
- 로그인/인증 없음
- 데이터베이스 없음
- 견적 이력 저장 없음
